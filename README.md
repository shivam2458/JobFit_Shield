# JobFit Shield

An AI-powered career platform that helps students and job seekers evaluate job postings, improve resumes, detect potential job scams, and track applications throughout their job search.

---

## Features (Planned)

- Resume Analysis
- Job Description Matching
- AI Resume Score
- Scam Job Detection
- Resume Improvement Suggestions
- Application Tracker
- User Authentication (JWT)
- Dashboard & Analytics
